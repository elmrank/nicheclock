nicheclock-suggest

This page is for the owner of a website whose server log shows the user agent below. It says what the visit was and how to stop it.

nicheclock-suggest/1.0 (+https://nicheclock.elmrank.com/bot; oss@elmrank.com)

What it is

The Your niche page of nicheclock has a button, Read my site. A person types the address of their own website and presses it. The nicheclock server then reads that site once to suggest topic words for their profile. There is no crawler that runs on its own: if no one presses the button, no request is made.

What one visit does

  1. It requests /robots.txt first and follows RFC 9309. If robots.txt answers with a server error, a 401, 403 or 429, or cannot be read, nothing else is requested. Any other 4xx answer (a 404, say) means there are no rules. It reads the group for nicheclock-suggest, else the group for *.
  2. It reads one sitemap (at most 300 KB), from the Sitemap: line of robots.txt or from /sitemap.xml, /sitemap_index.xml or /wp-sitemap.xml.
  3. It requests the first 64 KB of at most 8 pages from that sitemap, spread through it, only pages that robots.txt allows. It reads the page title.
  4. It follows at most one redirect, and never to another host. It sends no cookies. It stops for good on a 403 or 429 answer and does not retry.

That is at most 26 requests in one visit, one after the other, and no more than one visit to the same site a minute. A single visitor can press the button 5 times an hour.

What is kept

Nothing. The address, the sitemap and the titles are not stored or logged. The reply to the person holds only a short list of words and counts. See the privacy page.

How to block it

Add this to the robots.txt of your site and the bot will not read it:

User-agent: nicheclock-suggest
Disallow: /

You can also block by the user agent string above. To allow it only in part, use Disallow and Allow lines for that user agent as usual.
