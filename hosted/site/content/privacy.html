Privacy

This page says what the nicheclock website stores about you, and what it does not.

What the site counts

Page views are counted with a small first-party script. When you leave a page it sends:

  • the page path, without the query or the part after # (the filters you pick on the home page live after the # and never leave your browser);
  • how many seconds the page was visible and how far down you scrolled, in buckets;
  • a mobile or desktop flag;
  • the kind of site you came from (search, social, AI assistant, direct, internal or other), never the address of that site;
  • whether you clicked through to another page here.

We keep daily totals per page. We don't store one row per visitor, and we don't store your IP address, a cookie, a user agent or any identifier. The script reads the user agent only to skip crawlers and does nothing if the browser reports automation.

Cookies and third parties

The site sets no cookies. It stores nothing in your browser unless you save a niche profile (next section). It loads no third-party scripts, fonts or trackers. Links to sources and to GitHub take you to their sites, which have their own policies.

Your niche profile

The optional Your niche page keeps a profile (the topics you write about, a country, and anything else you type there) in this browser only, in localStorage under one key. It is never put in the address, so a copied link cannot carry it and the page counter above cannot see it. No profile data leaves your browser: the page downloads the same public data files as every visitor (the page, its scripts, the topic list and one list of Wikipedia pages for your country, all without a query string) and does the matching on your device. Typing a topic, saving, editing, switching profiles and exporting send nothing. The site has no copy of your profile, so it cannot restore it: Export JSON gives you a file to keep. Delete this profile removes it from the browser, and a private window forgets it when it closes. A shared computer keeps it until you delete it.

To check this yourself, open the developer tools, choose Network, and press Show my niche: you will see GET requests for data files and none that carries what you typed.

Network logs

Cloudflare serves the site and keeps its own network logs, which include IP addresses, under its own policies. We don't add to them, and we don't sell or share anything.

The self-hosted software

The nicheclock package sends nothing to us. It runs on your machine, keeps its data in your own directory, and talks only to the sources you enable and the model you configure. Your Search Console data and your model keys stay with you.

Accounts

There are no accounts, no sign-in and no API keys on this site at the moment, so we hold no personal data about you beyond what is written above. If that changes, this page changes first.
